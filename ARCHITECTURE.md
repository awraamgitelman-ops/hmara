## 1. Загальна схема архітектури

```
likemark-cloud/
├── server.js                      # Express-сервер продакшну (Railway)
├── package.json                   # Залежності та швидкі команди автоматизації
├── ARCHITECTURE.md                # Цей архітектурний довідник
├── PROJECT_BRIEF_AI.md            # Паспорт проєкту та офіційні юридичні реквізити
├── templates/                     # ЕТАЛОННІ HTML-КОМПОНЕНТИ (Single Source of Truth)
│   ├── site-header.html           # Головна шапка сайту (Top utility bar + Main nav)
│   ├── site-footer.html           # Підвал сайту (Колонки посилань + Реквізити)
│   ├── site-modals.html           # Модалки (Вхід, Реєстрація, Калькулятор, Лід-форма)
│   └── site-scripts.html          # Підключення базових модулів JS
├── scripts/                       # CLI-СКРИПТИ АВТОМАТИЗАЦІЇ
│   ├── sync-templates.js          # Синхронізація templates/ в усі сторінки public/
│   ├── extract-inline-styles.js   # Очищення HTML від інлайн-стилів
│   └── validate-site.js           # Перевірка цілісності посилань та реквізитів
├── public/                        # ПРОДАКШН-СТОРІНКИ ТА СТАТИЧНІ АСЕТИ
│   ├── *.html                     # Готові HTML-сторінки
│   ├── css/                       # Модульні таблиці стилів
│   ├── js/                        # Модулі клієнтської логіки
│   └── images/                    # Зображення, іконки, карти ЦОД
└── app/                           # Next.js роути (резервний шар)
```

## 3. Модулі стилів (CSS Guide)

Усі стилі зберігаються у `public/css/`. **Не редагуйте старі бандли, якщо потрібна зміна дизайну — використовуйте профільні файли:**

| CSS-файл | За що відповідає | Коли редагувати |
| :--- | :--- | :--- |
| **`site-header.css`** | **Шапка сайту** (Top bar + Main nav + Mobile drawer) | При зміні відступів, кольорів, висоти логотипу, шрифтів навігації |
| **`site-footer.css`** | **Підвал сайту** (Колонки, копірайти, соцмережі) | При оновленні реквізитів, посилань у футері, фону підвалу |
| **`site-theme.css`** | **Глобальна дизайн-система** | Змінні `--theme-primary`, шрифти Manrope, хлібні крихти, картки |
| **`speedtest.css`** | **Спідтест** | Стилізація графіків, спідометра, таблиць серверів |
| **`article.css`** | **База знань і статті** | Верстка тексту статей, кодових блоків, сайдбару |
| `fonts.css` | Локальні шрифти Manrope | Підключення локальних woff2-шрифтів (без Google Fonts) |
| `legacy-bundle.css` | Винесені утиліти Tailwind/Nuxt | Базові класи сітки та скидання стилів (не чіпати без потреби) |

## 4. Клієнтські JavaScript-модулі (`public/js/modules/`)

Клієнтська логіка розділена на ізольовані ES/Vanilla JS модулі:

1. **`auth.js`** — робота модальних вікон входу та створення акаунту (`#auth-modal`).
2. **`calculator.js`** — логіка хмарного калькулятора (повзунки vCPU, RAM, NVMe, розрахунок суми в грн/міс).
3. **`carousel.js`** — керування слайдером карток на головній сторінці та автоскролом логотипів партнерів.
4. **`configurator.js`** — інтерактивний підбір серверних конфігурацій.
5. **`consult.js`** — плаваюча кнопка швидкої консультації в кутку екрану.
6. **`modals.js`** — універсальний контролер відкриття/закриття модалок (закриття по `Esc` та оверлею).
7. **`speedtest.js`** — ядро вимірювання швидкості та пінгу до дата-центрів у Європі.

## 5. Правило Single Source of Truth для спільних блоків

> **Ніколи не змінюйте шапку чи футер на 10 окремих сторінках вручну!**
> 1. Внесіть правку в еталонний файл у папці `templates/`:
>    * `templates/site-header.html`
>    * `templates/site-footer.html`
>    * `templates/site-modals.html`
> 2. Запустіть скрипт синхронізації:
>    ```bash
>    npm run sync
>    ```
> Скрипт автоматично оновить усі сторінки сайту в `public/` менш ніж за 1 секунду.
